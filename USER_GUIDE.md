# Enhanced Channel Manager User Guide

This file is a compatibility entry point for older bookmarks. The maintained,
task-oriented operator guide starts at [ECM User Guide](docs/user_guide/index.md).

## Start here

- [Find Your Way Around the Operator Workspace](docs/user_guide/operator-workspace.md)
  explains the grouped sidebar, Dashboard drill-down, Settings safeguards,
  Channel Manager layout, and old-to-new URLs.
- [Set Up Your First Channels](docs/user_guide/getting-started/your-first-channels.md)
  walks through the first complete lineup.
- [Channels & Streams](docs/user_guide/channels-streams/index.md) covers
  day-to-day lineup work.
- [Troubleshooting](docs/user_guide/troubleshooting/index.md) collects common
  failures and diagnostic paths.

## Current workspace

ECM groups destinations in a sidebar:

| Group | Destinations |
|-|-|
| **Overview** | **Dashboard** |
| **Operations** | **Channel Manager**, **Guide**, **M3U Manager**, **EPG Manager**, **Logo Manager** |
| **Automation** | **Channel Pipeline**, **M3U Changes** |
| **Insights** | **Stats**, **Journal** |
| **System** | **Settings** |

The sidebar can be expanded or collapsed without changing routes or keyboard
order. For exact control names, keyboard instructions, screenshots at both
supported viewports, and legacy bookmark behavior, use the
[operator workspace orientation](docs/user_guide/operator-workspace.md).

Detailed task tutorials remain coordinated through the
[user-guide tutorial plan](docs/user_guide/README.md#planned-sections-bd-gsnw0)
instead of being duplicated here.
